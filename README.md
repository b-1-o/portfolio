# b-1-o Portfolio

> An immersive frontend developer portfolio focused on interactive UI, motion, visual design, and modern web experiences.

This portfolio is built as a React/Vite application with custom interactive components and a live project pipeline that keeps the showcased work synchronized with public GitHub projects.

## Highlights

- Interactive project showcase
- GitHub-powered project data
- Custom flex carousel
- Ripple distortion effects
- Responsive layouts
- Motion-focused UI
- Dark cinematic visual system
- GitHub Pages deployment through GitHub Actions

## Tech Stack

- React 19
- JavaScript
- Vite
- OGL / WebGL
- CSS
- GitHub Actions
- GitHub API

## Development

```bash
npm install
npm run dev
npm run build
```

## Deployment

The site is configured for GitHub Pages and uses GitHub Actions for deployment. The Vite base path is `/portfolio/`.
